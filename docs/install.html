Agent Deck 설치

Agent Deck은 Mac에서 돌아가는 코딩 에이전트 세션을 iPad 화면에 스트림 덱처럼 띄우는 웹 페이지입니다. 세션 하나가 키 하나이고, 키를 누르면 Mac의 Herdr 창에서 그 세션의 터미널로 포커스가 옮겨 갑니다.

무엇이 필요한가

서버는 의존성이 없는 Node 스크립트 하나라서 설치할 패키지가 없습니다. 다만 화면에 보여 줄 데이터를 Mac의 다른 도구에서 읽어 오기 때문에, 어떤 도구가 있느냐에 따라 보이는 범위가 달라집니다.

항목필수 여부없으면
macOS, Node 20 이상필수서버가 뜨지 않습니다
세션 스캔 스크립트필수키가 하나도 나오지 않습니다
Herdr 데스크톱 앱과 herdr-app CLI권장키는 보이지만 눌러도 터미널로 이동하지 않습니다
Claude Code 로그인선택계정 사용량 줄이 비어 있습니다
계정 전환 도구 cca선택계정을 눌러 기본 계정을 바꾸는 기능이 실패합니다

iPad는 Mac과 같은 Wi-Fi에 있거나, 둘 다 Tailscale 같은 사설망에 들어가 있어야 합니다.

설치와 실행

코딩 에이전트에게 맡기려면 README의 설치 프롬프트를 Claude Code 같은 에이전트에 붙여 넣으세요. 빠진 도구를 점검하고, 각각 없으면 무엇이 안 되는지 알려 줍니다. 직접 설치하려면 아래 순서를 따르세요.

git clone https://github.com/lcalmsky/agent-deck.git agent-deck
cd agent-deck
npm test      # 상태 모델 테스트, 의존성 설치 없이 바로 돕니다
npm start     # node server/server.mjs, 포트 8787

서버가 뜨면 터미널에 iPad에서 열 주소가 찍힙니다. 주소는 http://<Mac IP>:8787/?t=<토큰> 형태입니다. 이 주소로 처음 접속하면 토큰을 쿠키로 바꾸고, 그 뒤에는 토큰 없이 http://<Mac IP>:8787/만 열어도 됩니다.

토큰은 ~/.config/agent-deck/token에 저장됩니다. 주소가 다른 사람에게 노출됐다면 이 파일을 지우고 서버를 다시 시작하세요. 새 토큰이 발급되고 이전 쿠키는 더 이상 통하지 않습니다.

로그인할 때 자동으로 띄우기

scripts/launchd.sh install     # 등록하고 바로 실행
scripts/launchd.sh status      # 실행 상태 확인
scripts/launchd.sh uninstall   # 해제

launchd로 띄우면 iPad 주소는 터미널 대신 ~/.local/state/agent-deck/server.log에 찍힙니다.

iPad에서 열기

  1. Safari에서 서버가 알려 준 주소를 엽니다.
  2. 공유 버튼에서 "홈 화면에 추가"를 고르면 주소창 없이 전체 화면으로 열립니다.
  3. 오른쪽 아래 연결 키의 톱니바퀴에서 테마와 전체 화면을 고를 수 있습니다.
  4. 화면이 꺼지지 않게 하려면 iPad를 충전기에 연결해 두세요. 저전력 모드에서는 자동 잠금 시간이 짧아집니다.

데이터를 어디서 읽는가

아래 경로는 기본값이고, 환경 변수가 있는 항목은 다른 경로로 바꿀 수 있습니다.

데이터기본 경로환경 변수
세션 목록~/.config/herdr-app/mods/night-city-street/scan.shAGENT_DECK_SCAN
터미널 목록과 포커스~/.local/bin/herdr-appAGENT_DECK_HERDR
계정 사용량 캐시~/.local/state/herdr-tower/usage/*.json없음
계정 표시 이름~/.local/state/herdr-tower/labels없음
현재 기본 계정~/.local/state/herdr-tower/current없음
계정 전환~/.local/bin/cca use <계정>AGENT_DECK_CCA

포트와 바인딩 주소는 AGENT_DECK_PORT(기본 8787)와 AGENT_DECK_HOST(기본 0.0.0.0)로 바꿉니다.

세션 스캔 스크립트를 직접 만들 때

기본 스캔 스크립트는 Herdr의 night-city-street 모드에 들어 있고 이 저장소에는 포함되어 있지 않습니다. 그 모드가 없다면 같은 형식을 출력하는 스크립트를 만들고 AGENT_DECK_SCAN으로 지정하면 됩니다. 스크립트는 세션마다 JSON 한 줄을 출력합니다.

{"t":"s","sessionId":"a1b2","cwd":"/Users/me/git-repo/shop","status":"waiting",
 "statusUpdatedAt":1763350000000,"lastSentence":"이 마이그레이션을 돌릴까요?",
 "where":{"terminalId":"t1"}}
{"t":"meta","error":null}
  • status는 waiting, busy, idle, shell 중 하나입니다. waiting은 "확인 필요", busy는 "작업 중", idle은 "결과 도착"으로 보입니다.
  • busy인데 lastMeaningfulAt이 10분 넘게 갱신되지 않고 백그라운드 작업도 없으면 "멈춤"으로 바뀝니다.
  • where.terminalId가 herdr-app ls의 터미널 id와 맞아야 키를 눌렀을 때 그 터미널로 이동합니다.
  • 시각은 모두 밀리초 단위 epoch 값입니다. 그 밖에 읽는 필드는 server/model.mjs의 buildKeys와 detailOf에서 확인할 수 있습니다.

계정 사용량은 어떻게 가져오는가

서버는 5분마다 Claude Code가 macOS 키체인에 저장한 OAuth 토큰을 읽어 api.anthropic.com의 사용량 API를 호출합니다. 기본 계정은 키체인 항목 Claude Code-credentials를, 추가 계정은 ~/.claude-accounts/<계정> 설정 폴더에 대응하는 항목을 씁니다. 처음 호출할 때 macOS가 키체인 접근을 허용할지 물어봅니다.

  • 토큰은 Anthropic API로만 전송되고, iPad로 보내는 상태 데이터에는 들어가지 않습니다.
  • 토큰이 만료되면 서버는 갱신하지 않고 캐시 파일 값을 보여 줍니다. 해당 계정으로 Claude Code를 한 번 실행하면 토큰이 갱신됩니다.
  • 플랜 이름은 각 계정의 .claude.json에서 읽습니다. 플랜에 없는 제한 창은 표시하지 않습니다.

조작

동작결과
세션 키 누르기Mac의 Herdr 창에서 그 세션의 터미널로 이동합니다
세션 키 길게 누르기마지막 대화, 실행 중인 도구, PR, 작업 위치를 담은 카드가 열립니다
계정 누르기그 계정을 기본 계정으로 바꿀지 확인한 뒤 cca use를 실행합니다. 새로 시작하는 세션부터 적용됩니다
계정 길게 누르기제한 창별 사용률과 초기화 시각, Fable 사용 비중을 담은 카드가 열립니다

문제가 생겼을 때

iPad에서 접속이 안 됩니다

Mac 방화벽이 Node의 수신 연결을 막고 있는지 확인하세요. 회사 Wi-Fi처럼 기기 사이 통신을 막는 망에서는 같은 Wi-Fi에 있어도 접속되지 않으므로 Tailscale을 쓰는 편이 확실합니다.

키가 하나도 나오지 않습니다

스캔 스크립트를 직접 실행해서 JSON 줄이 나오는지 확인하세요. sh "$AGENT_DECK_SCAN" | head로 볼 수 있습니다.

키를 눌러도 터미널로 가지 않습니다

herdr-app ls가 터미널 목록을 출력하는지, 그 id가 스캔 결과의 where.terminalId와 같은지 확인하세요. 터미널을 찾지 못한 키는 흐리게 표시되고 눌리지 않습니다.
